# DressUP

A study project: the website of a **fictional** t-shirt store, built with plain HTML, CSS and JavaScript (no frameworks). It was my first project in my Information Systems degree, made with two classmates.

> This is not a real store. No products are sold and no payments are processed.

**Live site:** https://thuanykamers.github.io/DressUP/

## Features

- Product list with front and back images and a banner carousel
- Product pop-up with size selection
- Shopping cart saved in `localStorage` (change quantity, remove items, simulated checkout)
- Size guide page
- About us page
- Terms of service and privacy policy pages
- Cookie consent banner

The login, sign-up and password recovery screens are visual only. They are not connected to any back-end.

The site is in Portuguese. The t-shirt names are the phrases printed on the designs, and some of the jokes only work in Portuguese.

## Tech

- HTML5
- CSS3
- JavaScript (vanilla)
- GitHub Pages

## Run locally

No build step is needed. Clone the repository and open `index.html` in the browser, or serve the folder with any static server, for example:

```bash
npx serve .
```
